# 鲜生活（fresh-life）微信小程序

原生微信小程序实现（非 Taro/uni-app），**纯前端 Mock，无需启动后端服务**。所有数据通过
`wx.request` 拦截器进入本地内存数据库（`utils/mock/db.js`），写操作真实生效并通过
`wx.setStorageSync` 持久化，跨页面数据实时一致。

## 运行方式

1. 用微信开发者工具导入本目录（project.config.json 已设置 `urlCheck:false`）。
2. 直接编译预览即可，无需 `node https/server.js`（旧 https 服务已由内存 Mock 层替代）。

## 架构

```
app.js                  # wx.request 拦截器：所有 /api/* 请求进入本地 DB
app.json                # 4 Tab 结构不变（首页/会员+/购物车/我的）
app.wxss                # 全局设计规范：红色主题 #ff3b30，页面背景 #f5f6f7，卡片圆角16rpx
utils/
  api.js                # 统一请求封装（42 个接口方法）
  format.js             # 金额统一：分(整数)→元，禁止字符串价格参与计算
  decorate.js           # 展示字段装饰（*Yuan 两位小数）
  toast.js               # 统一 toast/modal/loading
  badge.js              # 购物车 tabBar 角标
  mock/seed.js          # 种子数据（36 商品、12 订单、地址、券、评价、积分、消息等）
  mock/db.js             # 内存数据库 + 路由 + 写操作（加购/下单/支付/评价/领券/签到/兑换/收藏）
components/pic/         # 通用图片组件：binderror 自动回退 /images/default.png，杜绝裂图
images/                 # 本地图片：商品图 goods-01..36.jpg、详情图、banner、金刚区、默认图、头像
pages/                  # 20 个页面（见下）
```

## 关键规则

- **金额**：内部一律为“分”（整数），展示层 `format.js`/`decorate.js` 转元并保留两位小数，禁止字符串参与计算。
- **写操作**：加购→购物车角标实时更新；下单→清空结算项、生成订单、mock支付→待发货；评价→订单标记已评价、+20积分、出现在详情评价区；领券→我的优惠券可用；签到→积分+5；兑换→扣积分、券自动入账。
- **图片**：全部本地图片，`pic` 组件 binderror 回退 `images/default.png`，无灰色裂图。
- **加载态/空态/分页**：列表页骨架屏呼吸动画、空态插图+文案+操作按钮、上拉每页10条、下拉刷新。
- **演示环境**：支付为 2 秒 loading 模拟，不产生真实交易（页面已标注）。
